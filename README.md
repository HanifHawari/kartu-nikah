# Undangan Pernikahan Hanief & Elsa

Undangan pernikahan digital berbasis web untuk acara Hanief dan Elsa. Situs ini menyajikan informasi pasangan, jadwal acara, lokasi, galeri, kisah perjalanan, hadiah, konfirmasi kehadiran, serta ucapan dan doa dalam tampilan responsif.

## Fitur

- Cover undangan interaktif dengan musik latar.
- Profil kedua mempelai dan tautan Instagram.
- Hitung mundur menuju hari pernikahan.
- Informasi akad dan resepsi beserta lokasi Google Maps.
- Tautan live streaming melalui Instagram, TikTok, dan YouTube.
- Galeri foto dan video dengan tampilan lightbox.
- Cerita perjalanan pasangan.
- Informasi hadiah serta konfirmasi melalui WhatsApp.
- Form RSVP dan ucapan yang tersimpan pada penyimpanan lokal browser.
- Navigasi responsif dan animasi antarelemen.

## Tech Stack

- React 19
- Vite 8
- JavaScript dan JSX
- CSS Modules
- Framer Motion
- Fancyapps UI/Fancybox
- React Icons
- Web Storage API (`localStorage`)
- Oxlint
